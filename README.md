# A/B Тест формы оплаты ЖКХ

## 📋 Условие задачи

**Контекст:**  
Команда платежей разработала новую форму оплаты ЖКХ с упрощённым заполнением реквизитов (автозаполнение). Текущая форма требует ручного ввода всех данных.

**Цель эксперимента:** Оценить влияние нового интерфейса на конверсию в успешную оплату.

**Воронка оплаты ЖКХ:**
1. Открыл форму оплаты
2. Ввёл реквизиты
3. Подтвердил платеж
4. Успешная оплата

**Ключевая метрика:** Конверсия из шага 1 в шаг 4 (успешная оплата).

**Гипотеза:** Новая форма с автозаполнением реквизитов увеличит долю успешных оплат ЖКХ.

**Длительность теста:** 30 дней (1–30 апреля 2024)

**Данные:**
Источник: `dannye-dlia-keisa-po-pa-cebbefc3-5b29-4f88-b6d4-3336c88d743f.xlsx`

Листы:
- `Пользователи` — информация о пользователях (группа, возраст, город, устройство)
- `Платежи` — данные о попытках оплаты (воронка по шагам)


**Задача:** Проанализировать результаты A/B теста и дать рекомендацию: запускать новую форму на всех пользователей или нет.

### 2. Разведочный анализ (EDA)
### 3. Статистический тест
- **Метод:** Двухвыборочный Z-тест для пропорций (proportions_ztest)
### 4. Визуализация
- Сравнение конверсии групп A и B
- Воронка по шагам
- Сегментный анализ (по устройствам, городам, возрасту)
### 5. Дополнительные проверки (необязателльные для задания)
- **U-критерий Манна-Уитни** для оценки среднего количества успешных попыток на пользователя
- **t-критерий Стьюдента** для оценки времени прохождения формы
